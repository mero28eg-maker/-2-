# موزّع السواقط — Streamlit (v3)

- جدول شهري قابل للتحرير (Quantity) + خانة **Fix (X)** لكل شهر.
- لو فعلت X وأدخلت كمية، يتم **تثبيت الشهر بهذه الكمية** (مش صفر بس).
- تلوين الصفوف المثبتة في جدول النتائج.
- قائمة منسدلة لاختيار P1 و Monthly Fee (مع خيار يدوي).
- الملخص يعرض **F8/F9** فقط.

## تشغيل
```bash
pip install -r requirements.txt
streamlit run app.py
```
